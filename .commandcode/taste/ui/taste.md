# ui

- Prefers a consistent design system across all admin pages — when adding/refactoring admin UI, make all pages (pipeline, ETL server, DB connection, audit logs, user management) share the same visual language (glassmorphism panels, gradient accents, shared SCSS class patterns like `.hub-title`, `.filter-bar`, `.content-area`, `.exensioreload-table`). User explicitly requested pages be updated to match a reference page's style rather than each page having its own ad-hoc styling. Confidence: 0.85
- Uses a custom SVG icon component (`app-glass-icon`) instead of Angular Material's `mat-icon` — icons are defined as inline SVG paths inside an `ngSwitch` block within the shared component. When new icons are needed, add a new `*ngSwitchCase` with hand-crafted SVG rather than using Material icon font or icon libraries. Confidence: 0.90
- Dual dark/light theme support is mandatory for all admin pages — dark theme uses glassmorphism (translucent panels, backdrop-blur, glowing accents); light theme uses white/light panels with dark text and visible borders. Light theme is applied via `:host-context(body.light-theme)` SCSS blocks alongside the dark default. Confidence: 0.90
